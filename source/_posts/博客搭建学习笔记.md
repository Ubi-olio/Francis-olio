## 技术栈概览

```
写 Markdown → hexo server 预览 → 满意了 git push → 自动部署
```

- **Markdown** — 写文章用的格式
- **Hexo** — 把 Markdown 变成网页的工具（Node.js）
- **Francis 主题** — 决定网页长什么样（EJS 模板 + CSS + JS）
- **Git** — 版本管理，部署也靠它

## 主题 JS 文件分布

主题的 JS 分两类：

### `themes/Francis/source/js/` — 在浏览器里跑的 JS

| 文件 | 作用 |
| --- | --- |
| `animation.js` | GSAP 动画，卡片进场、视差滚动、悬浮效果 |
| `header.js` | 导航栏滚动时的显示/隐藏行为 |
| `head.js` | 页面切换标题（activeTitle / inactiveTitle） |
| `highlight.js` | 代码块高亮和复制按钮 |
| `image-viewer.js` | 点击图片放大查看 |
| `tag-sankey.js` | 统计页的桑基图（D3.js） |
| `tasklist.js` | 复选框交互（我们自己加的） |
| `iconfont.js` | 图标字体加载 |

### `themes/Francis/layout/` — EJS 模板（服务端）

不是真正的 JS，是 Hexo 构建时用来生成 HTML 的模板，里面可以嵌入 `<% %>` 逻辑。

| 文件 | 对应页面 |
| --- | --- |
| `layout.ejs` | 所有页面的外壳（引入 CSS/JS） |
| `index.ejs` | 首页 |
| `posts.ejs` | 文章列表页 |
| `post.ejs` | 单篇文章页 |
| `about.ejs` | 关于页 |
| `stats.ejs` | 统计页 |
| `archive.ejs` | 归档页 |
| `_partial/` | 公共组件（头部、导航、页脚） |

> 改”文章”页的显示逻辑 → 动 `layout/posts.ejs`  
> 加全局交互行为 → 动 `source/js/` 里的文件
