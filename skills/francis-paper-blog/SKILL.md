# Francis 论文博客

用于将已阅读、讨论的论文整理为可阅读的博客，或调整此类文章的表现。尊重用户选择的内容范围；不因使用本技能自动扩写、保存文章或授权发布。

## 内容与层级

- 开头用一句“问题—方法”说明论文解决什么、如何解决。
- 使用读者熟悉的通用结构说明论文位置。Agent 可用“任务和观察 → LLM → 动作 → 环境反馈”；VLA 应按原文实际结构表达视觉、指令与动作生成，不强行把所有架构写成相同模块。
- 用红色标记结构图中新增加或改变的组件、连线，同时用“新增”等文字标识；基线结构使用蓝色。准确区分离线与在线，明确哪些模块固定、哪些更新。
- 正文重点适量加粗。
- 论文事实、教学例子、用户疑问与个人想法明确区分。教学例子注明不是论文实验。不得把 memory 更新写成 harness 代码修改，把模型自评写成客观成功保证。
- 用户指定的三部分等结构优先，不强行添加实验数字、结论章或固定章节数。

## 博客样式约定

目标仓库：`/Users/lichen/PycharmProjects/Francis-olio`。复用 `source/css/style.css` 中 `paper-*` 组件，避免往每篇文章写一套内联样式。

- `.paper-summary`：开头问题—方法总结。
- `.paper-grid` 内放 `.paper-card`：定义、模块对比。卡片边框 `#95A9D8`，浅蓝背景。
- `.paper-flow`：流程示意；`.paper-example`：注明教学例子的说明块。与卡片同一蓝色体系。
- `.paper-question`：用户疑问；`.paper-note`：概念边界提示。浅草绿底 `#f1faeb`，标题 `#3b941d`，强调线 `#59b832`，边框 `#8ccf67`。不用亮绿 `#5EEA5D` 或暖橙色。
- `.paper-callout-title`：提示块内的标题；正文仍为可读的深色。深色模式使用组件变量的适配颜色。
- `.paper-diagram`：SVG 结构图容器；`.paper-caption`：图注。优先使用仓库本地 SVG/图片，注明自行整理或原图来源，图上文字须在手机端可读。
- 表格用于真实对比；宽表允许横向滚动。不要给每一段都套卡片。

HTML 块内直接使用 `<p>`、`<strong>` 等，不假定 Markdown 一定会在块内解析。例如：

```html
<aside class="paper-question">
<p class="paper-callout-title">我的疑问：什么时候停止？</p>
<p><strong>单个任务：</strong>解释当前执行的停止条件。</p>
<p><strong>经验积累：</strong>解释跨任务更新何时结束。</p>
</aside>
```
